# Tamiya Colors

タミヤカラーの検索インターフェイス

Next.js (App Router) + React + MUI で構築し、静的エクスポートで GitHub Pages に公開しています。

![tamiyacolors](https://github.com/hidekingerz/Color-Chart/assets/6613700/cc79edff-acd6-4fa4-9a93-d66a6ce65d41)

## ローカル環境での起動
```
npm i
npm run dev
```
